# 🧼 Besties Soaps TCG

Official documentation, crafting mechanics, and asset catalog for **Besties Soaps TCG**—an artisanal soap-making digital collectible trading card game on the **WAX blockchain** by **Besties Gone Crafty Boutique**.

---

## 🌟 Project Overview

**Besties Soaps TCG** brings real-world, small-batch handmade soap crafting onto the carbon-neutral WAX blockchain. Collectors gather raw crafting ingredients, equip their studio tools, upgrade their soap molds to scale production capacity, and blend vibrant single-color soap bar NFTs via **Mintyblocks**.

* **Blockchain:** WAX (Worldwide Asset eXchange)
* **Collection:** Besties Gone Crafty Boutique (`bestiesbouti`)
* **Drops & Blending Platform:** Mintyblocks
* **Supported Wallets:** WAX Cloud Wallet & Anchor

---

## 🧩 Core Studio NFTs

Every soap bar in Besties Soaps TCG is crafted using four core asset types:

| Asset Name | Card Category | Crafting Behavior | Description |
| :--- | :--- | :--- | :--- |
| **Melting Pot** | Utility Tool | **Returned** after craft | The essential studio vessel required in every blend to melt the soap base and infuse pigment. |
| **Soap Molds** | Capacity Equipment | **Returned** after craft *(Burned only when upgrading)* | Determines how many bars you pour in a single batch (1-Bar, 3-Bar, 6-Bar, or 12-Bar). |
| **Aloe Vera M&P Base** | Base Ingredient | **Burned** (`1x` per bar) | The soothing foundational melt-and-pour soap base required for every bar produced. |
| **Mica Powders** | Colorant Ingredient | **Burned** (`1x` per bar) | Vibrant mineral pigments available in **Red, Orange, Yellow, Green, Blue, and Purple**. |

---

## 🧊 Mold Upgrade Progression

Start with a **1-Bar Single Mold** and combine lower-tier molds to unlock larger batch capacities:

| Mold Tier | Upgrade Recipe (Burned) | Batch Output | Crafting Rule |
| :--- | :--- | :--- | :--- |
| **1-Bar Single Mold** | Starter / Pack Drop | **1 Soap Bar** | Single-color pour |
| **3-Bar Trio Mold** | `3x` 1-Bar Single Molds | **3 Soap Bars** | Single-color batch pour |
| **6-Bar Loaf Mold** | `2x` 3-Bar Trio Molds | **6 Soap Bars** | Single-color batch pour |
| **12-Bar Master Slab** | `2x` 6-Bar Loaf Molds | **12 Soap Bars** | Maximum batch efficiency |

## 🔥 Single-Color Crafting Mechanics

All initial studio recipes follow a strict **one-color-per-bar** rule. Depending on your equipped mold tier, a standard Mintyblocks blend follows this formula:

* **1x Melting Pot NFT** *(Returned)*
* **1x Soap Mold NFT** *(Returned — 1, 3, 6, or 12-Bar)*
* **Nx Aloe Vera M&P Base NFTs** *(Burned — matches mold capacity)*
* **Nx Single-Color Mica Powder NFTs** *(Burned — Red, Orange, Yellow, Green, Blue, or Purple)*
* **Result:** **Nx Finished Single-Color Aloe Soap Bar NFTs**
